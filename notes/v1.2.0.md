## v1.2.0 更新日志

本次为大版本更新，新增了完整的混音器、音素时机调节、工程保存、暗色模式、USTX 互通等核心功能，全面扩展了 webUTAU 的可用性。建议所有用户更新。

### 新增功能
- **音素时机调节器**：可精细调整每个音素的时长与起止位置。
- **工程保存系统**：保存/加载 `.webutau` 工程、dirty 跟踪、工程名牌、离开守卫、启动时自动恢复未关闭的项目。
- **出品级混音器**：每轨立体声 pan、单轨 insert 效果链（EQ/Compressor）、主总线效果链（EQ + Compressor + Limiter）、LUFS 响度计与一键自动达标。
- **完整混音器面板视图**：通道条、把手、旋钮、M/S、send、master strip、insert 槽参数浮窗，并与编辑器互斥、可拖动调整高度。
- **USTX 双向无损导入导出**：与 OpenUtau 工程文件 100% 互通，影子保留 webUTAU 独占字段（AI 音高、混音参数等）。
- **钢琴卷帘标准 note 操作**：完整的音符级选择、移动、复制、删除等编辑动作。
- **持久化音高预测结果**：保存工程后再打开仍可看到 AI 预测的密集音高曲线，无需重算。
- **暗色模式**：完整深色主题，跟随系统或手动切换。
- **多语言本地化（i18n）**：支持界面语言切换。
- **底部状态栏**：实时显示项目名、BPM、播放头位置、当前编辑器与选区信息。
- **全局 ESC 栈式调度**：按优先级关闭模态、Quick Lyric、底部 dock、钢琴卷帘。
- **AI 填词**：调用 LLM 自动生成歌词，Quick Lyric 提供候选轮播条与"再来一版"按钮。
- **桌面版 AI Key 安全升级**：迁移至 OS 钥匙库（macOS Keychain / Windows Credential / Linux Secret Service）。
- **轨道颜色自定义**与**轨道重命名**。
- **主输出 stereo 峰值表**。

### 优化
- 初次播放加载速度大幅提升：采样按需懒加载、Round-robin 懒加载、分块扫描不再整体阻塞。
- AI 写词速度优化、新增错句重投机制提升成功率。
- 引入 `--radius` / `--gap` / `--hover-bg` 等设计 token，全站共 ~190 处样式统一替换。
- 模态、底部 dock、Quick Lyric、Inspector 加 120ms 淡入淡出，消除按一下卡一下的微卡顿。
- Tone down 22 处过度的 hover 反馈。
- 侧边栏宽度自适应并初步重构。
- 减少打包体积、删除重复构建产物。
- 改进 AI 写词与 textarea 的解耦显示。

### 修复
- 修复 USTX 导入闭环多类失真：voice_part / note position 双叠加污染、tempo `time=null` 兜底导致播放头错位、开头缺音符、AI 音高被覆盖等。
- 修复打开工程时不自动恢复渲染任务、未渲染工程改歌词后卷帘不更新。
- 修复调整 send 后保存工程文件变为 0 字节。
- 修复混音器 docker 拖动卡顿、点击电平表呼出的 docker 无法正常关闭。
- 修复亮暗色切换过渡卡顿、暗色模式下个别 UI 缺失或按钮对比度过低、三工具按钮不显示选中态。
- 修复主题色切换按钮图案与实际主题色不同步。
- 修复导入工程后直接点击人声轨快速填词不弹窗。
- 修复保存工程时悬空的预测中间态与音色转换 server 引用。

### 如何使用？
- **Mac（Apple Silicon）** — 下载 `aarch64.dmg` 文件
- **Windows** — 下载 `x64-setup.exe` 文件
